## Rules for all SOPs / Peraturan umum
1. Follow steps in order. / Ikut langkah mengikut turutan.
2. Tick the checkbox only after the step is done. / Tanda hanya selepas siap.
3. If unsure, ask the supervisor — never guess on food safety. / Jika ragu, tanya penyelia — jangan agak-agak tentang keselamatan makanan.
4. Change an SOP only with Pkin's approval; note the date at the bottom. / Ubah SOP hanya dengan kelulusan Pkin; catat tarikh di bawah.
