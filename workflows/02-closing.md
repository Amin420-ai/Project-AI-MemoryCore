# 02 — Closing / Tutup Kedai

**Who / Siapa:** Closing staff / Staf penutup · **When / Bila:** `[masa tutup]` + 45–60 min

## Steps / Langkah
- [ ] Flip sign to CLOSED; finish last orders. / Tukar papan ke TUTUP; siapkan pesanan terakhir.
- [ ] Cash-up and close POS (SOP 06). / Kira tunai dan tutup POS (SOP 06).
- [ ] Label, cover, store leftovers in fridge; throw anything left out >2 hours. / Label, tutup, simpan baki dalam peti sejuk; buang makanan terdedah >2 jam.
- [ ] Clean & sanitise: espresso machine (backflush, steam wand), grinder, blenders, counters. / Cuci & sanitasi: mesin espresso (backflush, wand wap), pengisar, pengisar buah, kaunter.
- [ ] Wash utensils, cups, trays; air-dry. / Cuci perkakas, cawan, dulang; kering angin.
- [ ] Sweep and mop floor; clean toilets. / Sapu dan mop lantai; cuci tandas.
- [ ] Empty bins; take rubbish to outside bin; close lids. / Kosongkan tong sampah; buang ke tong luar; tutup rapat.
- [ ] Record fridge temperature again. / Catat suhu peti sejuk sekali lagi.
- [ ] Turn off equipment, lights, aircond, fans, gas. / Matikan peralatan, lampu, aircond, kipas, gas.
- [ ] Lock doors/windows; put cash in `[tempat simpanan]`. / Kunci pintu/tingkap; simpan wang di `[tempat]`.
- [ ] Send daily report (SOP 10). / Hantar laporan harian (SOP 10).

## If something goes wrong / Jika berlaku masalah
Cash mismatch, damage, or break-in signs → do not leave; call supervisor/Pkin; record in SOP 09. / Wang tak tally, kerosakan, tanda pecah masuk → jangan tinggalkan; hubungi penyelia/Pkin; rekod di SOP 09.
