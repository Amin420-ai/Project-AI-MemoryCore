# 10 — Daily Report to Pkin / Laporan Harian kepada Pkin

**Who / Siapa:** Supervisor on closing shift · **When / Bila:** before leaving, via `[WhatsApp / e-mel]` to Pkin

## Template / Templat (copy & fill / salin & isi)
```
LAPORAN HARIAN — [tarikh] — Penyelia: [nama]
1. Jualan / Sales: RM[__]  (tunai RM[__], QR/kad RM[__])
2. Tunai tally / Cash: OK | beza RM[__] sebab: [__]
3. Pelanggan / Customers: [bil.]   Aduan / Complaints: [bil. + ringkas]
4. Stok perlu order / Low stock: [senarai]
5. Pembaziran / Waste: [item, qty]
6. Suhu peti / Fridge temps: OK | masalah: [__]
7. Peralatan / Equipment: OK | rosak: [__]
8. Insiden / Incidents: tiada | [ringkas — rujuk SOP 09]
9. Staf / Staff: [hadir, lewat, cuti]
10. Nota untuk esok / Notes for tomorrow: [__]
```

## Checklist before sending / Semak sebelum hantar
- [ ] Figures match POS report and cash sheet (SOP 06). / Angka sepadan dengan laporan POS.
- [ ] Any food-safety or cash issue flagged at the top. / Isu keselamatan makanan/wang di atas sekali.
- [ ] Report saved in `[folder / buku]`. / Simpan laporan.

## Weekly summary / Ringkasan mingguan `[hari]`
Total sales, best sellers, waste total, incidents, stock cost, staff issues, one improvement for next week. / Jumlah jualan, produk laris, pembaziran, insiden, kos stok, isu staf, satu penambahbaikan.
