# 03 — Order & Service / Pesanan & Layanan

**Who / Siapa:** All staff / Semua staf

## Taking an order / Ambil pesanan
1. Greet within 10 seconds: `[ayat sambutan, cth. "Selamat datang, nak order apa?"]`. / Sambut dalam 10 saat.
2. Ask about allergies (nuts, milk, egg, gluten, seafood) and special requests. / Tanya alahan dan permintaan khas.
3. Repeat the order back; confirm the total. / Ulang pesanan; sahkan jumlah.
4. Key into POS; give order number/ticket. / Masukkan dalam POS; beri nombor pesanan.
5. Take payment before preparing `[atau selepas — isi dasar]`. / Terima bayaran.

## Preparing / Penyediaan
- [ ] Wash hands before starting and after touching money, phone, face. / Cuci tangan sebelum mula dan selepas pegang wang, telefon, muka.
- [ ] Check ticket against cup/plate label. / Semak tiket dengan label.
- [ ] Follow the recipe card `[pautan resipi / recipe link]` exactly. / Ikut kad resipi.
- [ ] Use tongs/gloves for ready-to-eat food; never bare hands. / Guna penyepit/sarung tangan untuk makanan siap makan.
- [ ] Target time: drinks `[x]` min, food `[y]` min. / Sasaran masa.

## Serving / Hidang
1. Check order is complete and tidy; call number/name. / Semak lengkap dan kemas.
2. Say clearly if it contains allergens. / Nyatakan jika ada alergen.
3. Clear and wipe tables within 5 min after guests leave. / Kemas dan lap meja dalam 5 minit.

## Complaints / Aduan
1. Listen without interrupting; apologise. / Dengar tanpa mencelah; mohon maaf.
2. Remake or refund per `[dasar, cth. buat semula percuma]`. / Buat semula atau bayar balik.
3. If food-safety related (hair, insect, illness) → keep item, call supervisor, record in SOP 09. / Jika melibatkan keselamatan makanan → simpan item, hubungi penyelia, rekod SOP 09.
