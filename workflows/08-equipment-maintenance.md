# 08 — Equipment Maintenance / Penyelenggaraan Peralatan

**Who / Siapa:** Supervisor assigns; all staff report faults / Semua lapor kerosakan

## Daily / Harian
- [ ] Espresso machine: purge group heads, backflush, wipe wand after each milk use. / Mesin espresso: purge, backflush, lap wand.
- [ ] Grinder: check grind size; clean hopper chute. / Pengisar: semak kehalusan.
- [ ] Fridge/freezer: temp log, door seals clean, no ice build-up. / Peti: log suhu, getah pintu, tiada ais berlebihan.
- [ ] Blender/microwave/oven: clean after use. / Pengisar, ketuhar: bersih selepas guna.

## Weekly / Mingguan `[hari]`
- [ ] Descale kettle/water boiler if scale visible. / Buang kerak.
- [ ] Check water filter date; replace on schedule `[tarikh]`. / Semak tarikh penapis air.
- [ ] Clean fridge drain, vents, shelves. / Cuci saluran, ventilasi, rak.

## Monthly / Bulanan
- [ ] Gas cylinder, hoses, stove: check for leaks with soapy water; replace worn parts. / Silinder gas, hos: uji bocor dengan air sabun.
- [ ] Fire extinguisher: check gauge/date; staff know location. / Pemadam api: semak tolok/tarikh.
- [ ] Service espresso machine per supplier `[tarikh]`. / Servis mesin.

## Equipment log / Log peralatan
`[peralatan | tarikh | masalah | tindakan | kos | teknisi/no. tel.]`

## Fault procedure / Jika rosak
1. Stop using; put "ROSAK / OUT OF ORDER" sign. / Berhenti guna; letak tanda ROSAK.
2. Tell supervisor; supervisor calls repair `[no.]`. / Beritahu penyelia.
3. Fridge fails → move food to working unit, check temps, discard food above 5°C for > 2 h; record in SOP 09. / Peti rosak → pindah makanan; buang jika >5°C lebih 2 jam.
