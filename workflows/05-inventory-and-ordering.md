# 05 — Inventory & Ordering / Stok & Pesanan Bekalan

**Who / Siapa:** Supervisor (counts by any staff) · **When / Bila:** daily quick count, weekly full count `[hari]`

## Daily quick count / Kiraan harian (closing)
- [ ] Count key items: susu, biji kopi, roti, telur, gula, cawan, penutup, `[tambah]`. / Kira item utama.
- [ ] Write in stock sheet: `[item | baki | paras minimum | perlu order?]`. / Catat dalam helaian stok.
- [ ] Any item below minimum → mark ORDER. / Item bawah minimum → tandakan ORDER.

## Weekly full count & order / Kiraan penuh & order mingguan
1. Count everything, including freezer and dry store. / Kira semua.
2. Check dates; remove expired; record waste (item, qty, reason). / Semak tarikh; buang luput; rekod pembaziran.
3. Order qty = (usage per week × `[x]` weeks) − current stock. / Kuantiti order = (guna seminggu × minggu) − stok.
4. Send order to supplier before cut-off `[masa]`. / Hantar order sebelum waktu akhir.
5. Record in order log: date, supplier, items, price, expected delivery. / Rekod dalam log order.

## Receiving delivery / Terima bekalan
- [ ] Check against order and invoice (qty, price). / Semak dengan order dan invois.
- [ ] Check dates, packaging, smell; reject damaged items. / Semak tarikh, bungkusan, bau; tolak yang rosak.
- [ ] Chilled/frozen items to fridge/freezer within 15 min; check temp. / Barang sejuk ke peti dalam 15 minit.
- [ ] Label with delivery date; FIFO. / Label tarikh terima.
- [ ] Sign invoice; note shortages and tell supplier same day. / Tandatangan invois; lapor kekurangan hari sama.
