# 01 — Opening / Buka Kedai

**Purpose / Tujuan:** Ready, clean, safe café before first customer. / Kafe siap, bersih, selamat sebelum pelanggan pertama.
**Who / Siapa:** Opening staff / Staf pembuka · **When / Bila:** `[masa, cth. 7:00 pagi]` (30–45 min before opening)

## Steps / Langkah
- [ ] Wash hands 20 sec, wear apron, hair cover, clean uniform. / Cuci tangan 20 saat, pakai apron, penutup rambut, pakaian bersih.
- [ ] Check for pests, leaks, bad smells; report at once. / Periksa perosak, kebocoran, bau busuk; lapor segera.
- [ ] Turn on lights, aircond, fans, water heater, equipment. / Hidupkan lampu, aircond, kipas, pemanas air, peralatan.
- [ ] Read fridge/freezer temperature, write in log (see SOP 04). / Baca suhu peti sejuk/beku, catat dalam log (lihat SOP 04).
- [ ] Check stock dates; throw expired items (FIFO). / Semak tarikh luput; buang yang tamat (FIFO).
- [ ] Heat espresso machine; run test shot; check grinder. / Panaskan mesin espresso; uji satu shot; periksa pengisar.
- [ ] Wipe tables, counters, menu, door handles with sanitiser. / Lap meja, kaunter, menu, pemegang pintu dengan sanitiser.
- [ ] Stock cups, lids, straws, napkins, sugar, syrups. / Isi cawan, penutup, penyedut minuman, napkin, gula, sirap.
- [ ] Count float and open POS (SOP 06). / Kira wang modal dan buka POS (SOP 06).
- [ ] Prep: `[isi: roti, topping, susu, dll.]` — label with date/time. / Sediaan: label tarikh/masa.
- [ ] Flip sign to OPEN at `[masa]`. / Tukar papan tanda ke BUKA.

## If something goes wrong / Jika berlaku masalah
Fridge above 5°C, no water/power, equipment fault → tell supervisor; do not serve affected food. / Peti sejuk melebihi 5°C, tiada air/elektrik, kerosakan → beritahu penyelia; jangan hidang makanan terjejas.
